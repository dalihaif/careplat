# 照护管理平台 careplat

**护工记、家属看**：给卧床病人 / 康复期病人 / 慢病老人的家庭照护做记录与提醒的本地平台。
把翻身、喂药、体征、康复、日记和花销落到一处，谁也不用靠记性。

> 架构源自同一作者的 [狗狗管理平台 dogplat](https://github.com/dalihaif/dogplat)：
> Flask + SQLite 单文件 + Bootstrap 5 + Chart.js，全本地化、离线可用。

**作者**：李海峰 · 大理大学第一附属医院 · dalihaif@qq.com · [github.com/dalihaif](https://github.com/dalihaif)

## 功能

| 模块 | 说明 |
|---|---|
| 📋 今日照护 | 按照护等级自动排任务：卧床=翻身每 2 小时 + 皮肤检查；全协助/半协助=三餐+饮水；用药按时间表自动进时间轴 |
| 💊 用药管理 | 药品时间表（名/剂量/时间点/用法），服药打卡，漏服自动预警 |
| 📈 体征记录 | 血压/心率/体温/血氧/血糖/体重，趋势图 + 异常标红 + 就医参考线 |
| 💪 康复训练 | 训练项目、完成率统计、安全提示（踝泵、防跌倒等） |
| 📒 照护记录 | 全部打卡记录，按类型/日期/关键词筛选，可编辑删除 |
| 📖 照护日记 | 图文/视频上传（自动缩略图），记录恢复过程 |
| 💰 记账 | 护工工资/药品/耗材/复诊，饼图 + 月度趋势 + CSV 导出（Excel 不乱码） |
| 🏥 医疗档案 | 就诊/检查/手术记录 + 复诊提醒（提前 7 天预警） |
| 📊 周报 | 任务完成率、服药、翻身、饮水的统计与下周建议；**一键转发**（复制全文 / 邮件 / 下载 txt / 打印） |
| 📚 照护知识 | 内置压疮/用药/康复/饮食/体征/照护者心理科普 |
| 🗂 多病人 | 每位病人独立档案与数据；状态（在照护/康复出院/转院/去世）变更留痕 |
| ⚡ 一键打卡 | 时间轴上点 ✓ 直接记完成，不弹窗、不刷新；📝 仍可填详细内容 |
| 📬 邮件通知 | 漏打卡 / 翻身超时 / 体征异常 / 复诊提醒自动发家属邮箱（同类提醒每天最多一封）；后台每 10 分钟自动巡检 |
| 🖨 床头卡 | A4 打印版：用药时间表 + 例行任务 + 急症清单 + 紧急电话，贴床头 |
| 🧳 复诊清单 | 自动生成「要带的东西 + 在服药品 + 想问医生的问题」 |

## 快速开始

```bash
pip install -r requirements.txt
python app.py            # 默认 http://127.0.0.1:5810
```

手机使用：电脑和手机连同一 WiFi，手机浏览器打开「局域网地址」（启动时打印，也写在 `data/访问地址.txt`），
菜单里选「添加到主屏幕 / 安装应用」即可像 App 一样打卡。

想先看效果：`python seed_demo.py` 灌 3 位演示病人（数据独立在 `data/demo/`），再
`CAREPLAT_DB=data/demo/demo.db CAREPLAT_PORT=5811 python app.py` 启动演示实例。

### 打包成 exe（给不用装 Python 的电脑）

```bash
打包.bat        # 或：python -m PyInstaller careplat.spec --noconfirm
```
产物在 `dist/照护管理平台/`，整个文件夹拷到任何 Windows 电脑，双击 exe 就能跑，
数据自动存在 exe 旁边的 `data/` 目录。

### 备份

```bash
自动备份.bat                    # 备到项目 backups 目录
自动备份.bat Z:\careplat-backup # 备到 NAS 映射盘 / UNC 路径
# 或：python backup.py <目标目录> --keep 14
```
备份内容 = 数据库（在线备份 API，运行中备份也不会坏）+ 照片视频，自动保留最近 14 份。
建议每周双击一次，或用 Windows 任务计划程序定时跑 `backup.py`。

### 公网访问（手机 4G / 外地家属也能看）

```bash
启动公网访问.bat          # 或：python tunnel.py
```

做了三件事：拉起本地服务（没跑的话）→ 开一条 Cloudflare 隧道 → 打印 `https://xxx.trycloudflare.com`。

- 屏幕上的地址**每次启动都会变**（快速隧道特性），变了重新看窗口 / `data/公网地址.txt`
- 电脑要开着、窗口不能关；关掉只断公网，局域网照常
- 隧道客户端 `tools/cloudflared.exe` 缺失时会自动下载（走国内镜像）

### 访问密码

**首次启动自动生成随机密码**，写在 `data/访问密码.txt`，启动横幅也会显示。
手机/电脑第一次打开输一次，记 30 天。改密码：`通知设置 → 访问密码`。
连错 5 次锁 10 分钟。`/api/health` 免密（给监控用）。

## 环境变量

| 变量 | 作用 |
|---|---|
| `CAREPLAT_DB` | 指定数据库文件（多实例/自检用） |
| `CAREPLAT_UPLOADS` | 指定照片视频目录 |
| `CAREPLAT_PORT` | 端口，默认 5810 |
| `CAREPLAT_NO_AUTH` | `1` = 关闭登录门（**只给自检/调试用**，别在真机上设） |

## ⚠️ 安全须知

- **所有页面都要访问密码**，公网访问一律走 HTTPS 隧道；仍然建议只把地址给家人。
- 密码别用生日/手机号；`data/访问密码.txt` 就是钥匙，别随手发群里。
- 体征参考区间来自通用科普，异常提醒仅供留意，**不构成诊断**；用药请严格遵医嘱。

## 备份

备份 = 复制 `data/careplat.db` **加** `data/uploads/` 整个目录，两样都拷才算备份完整。
