CarePlat · v1.0

照护管理平台

护工记，家属看。
卧床、康复、慢病病人的照护任务打卡、用药提醒、体征趋势、康复训练、日记与记账——全在本地一台电脑上跑，数据不出门。

Flask + SQLite 离线可用 免登录 · 局域网 exe 单文件可跑 开源 · GitHub

⚠️ 这个网址看到的是项目主页，不是平台本身

GitHub Pages 只能放静态网页（HTML/CSS/图片）。本平台背后是 Python 服务 + SQLite 数据库，Pages 跑不了后端，所以页面点不进去功能。

要用它，得在一台电脑上启动服务，然后用浏览器访问那台电脑。三分钟能起，见下方步骤。

三步开始使用

Windows 电脑，装过一次以后每次双击即可

1

拿到程序

用打包版最省事：解压 照护管理平台 文件夹，里面就一个 .exe，不用装 Python。

2

双击启动

双击 exe（或源码版的 启动服务.bat），出现黑窗口别关，它就是服务本体。

# 源码版也可以命令行起
python app.py
3

浏览器打开

本机用下面地址；手机连同一个 WiFi，把 127.0.0.1 换成电脑的局域网 IP。

http://127.0.0.1:5810

电脑、手机都能看

同一个 WiFi 下，手机浏览器直接开，不用装 App

🖥 这台电脑

启动服务后打开：

http://127.0.0.1:5810

📱 手机 / 平板

先查电脑的局域网 IP（命令行输 ipconfig），手机连同一个 WiFi 再访问：

http://192.168.1.x:5810

它管什么

按「照护等级」自动排任务，不是让你自己记

📋

今日照护

卧床自动排每 2 小时翻身、三餐、饮水、皮肤检查；点一下就算打卡

💊

用药管理

一药一行、一天多时段；过了点没打卡就报「漏服」

🩺

体征趋势

血压、血糖、体温、血氧等 7 项，画趋势图，超标分级提醒

🦵

康复训练

项目、时长、完成组数，看得到进步曲线

🗂

医疗档案

就诊记录、诊断、用药调整；复诊自动提醒

📖

照护日记

文字 + 照片 + 视频，按天归档，家属随时翻

💰

记账

药费、护理费、耗材，可导出 CSV

📊

周报转发

一键生成纯文本周报，复制 / 邮件 / 下载给外地家人

📧

邮件通知

漏药、翻身超时、体征异常自动发家属邮箱，一天最多一封

🖨

床头卡

A4 打印：用药时间表、急症清单、大字紧急电话，贴床头

🧾

复诊清单

证件、在服药品单、最近体征、想问医生的问题，打印带走

💾

备份

在线备份数据库 + 照片视频，自动留最近 14 份，可备到 NAS

⚠️ 使用前必须知道

这是「家庭内部工具」，不是医疗系统

  • 没有登录密码：只能在家里局域网用，绝对不要做端口映射/内网穿透暴露到公网——里面有病人姓名、病历、用药。
  • 不是诊断工具：体征参考区间是科普常识，异常提示只提醒你「该问医生了」，不能代替医生判断。
  • 数据在本机：数据库就是 data/careplat.db 一个文件，照片视频在同目录 uploads/。备份要两个一起拷，只拷 db 会丢照片。
  • 换电脑：把整个程序文件夹拷过去即可，数据跟着走。

技术栈

为「没网也能用、老人家里也能跑」选的，没有任何云依赖

🐍

Flask + waitress

Python 后端，8 线程，Windows 上稳

🗄

SQLite 单文件

整个库就是一个 .db，拷贝即备份

🎨

Bootstrap 5 + Chart.js

UI 与图表全部本地化，断网照常显示

📦

PyInstaller

打包成 exe，目标机不用装 Python
